# 時光渡口・記憶漣漪｜語音導覽 Prototype

單頁式 (SPA)、完全離線運行的展覽語音導覽網頁。專為 iPad 第七代（3:4 直式）設計，
可直接用 Safari 開啟 `index.html`，或包成 App 內嵌 WebView 使用，全程不需要網路連線。

## 檔案結構

```
index.html          ← 整個網頁（HTML/CSS/JS 都在同一檔案內，方便離線部署）
audio/
  track01.mp3 ... track10.mp3   ← 目前為「靜音佔位音檔」，時長已依示意設定，
                                    方便測試播放/暫停/進度條/跳轉功能。
                                    正式上線前請替換成真正的語音導覽錄音，
                                    檔名維持 track01.mp3 ~ track10.mp3 即可自動對應。
```

## 目前功能

  （工作區域_1.png）標定座標，不規則分布、無需捲動。

  - 同心圓角方框由中心向外**明顯由粗漸細**（線寬與亮度都是核心處最強，
    往外逐圈遞減），並改為**較精簡的圈數**，不再密密麻麻
  - 轉角改為大幅圓潤的「圓角方形（squircle）」比例，不再是生硬的圓角矩形
  - 每一圈的間斷（虛線缺口）改為亂數但可重現的不規則長短分布，模擬手繪水波的質感
  - 左上到左下沿著方框邊緣、貼合圓角弧線分布的 9 種彩色小色條/色弧

  - 每個水波紋會有 3 圈由核心持續向外擴散、逐漸淡出的「流動水紋」，
    營造出水波不斷從中心盪漾出去的動態感

  （中央 05 最大、右上 02、右側 03、右下 06/04、左側 07/08、左下 10、
  下方 01/09），但中心維持顯示**中文主題文字**（示意圖上是編號，此處保留

  - 左上角「回上一頁」圓形按鈕

  - 可拖曳 / 點擊的播放進度條，含目前時間與總時長
  - 下方逐字稿卡片，可獨立捲動閱讀

  背景漸層仿照主視覺由深青轉米杏再到赭紅。
- 水波紋按鈕會有極輕微的「呼吸」動畫，點擊時會有水波擴散的回饋動畫。
- 若音檔缺漏或無法載入，會在播放區顯示提示文字，但逐字稿仍可正常閱讀，
  不影響其餘功能。

## 如何替換成正式內容

打開 `index.html`，搜尋 `TOURS` 這個 JavaScript 陣列（約在檔案中段），
每一則導覽都是一個物件：

```js
{
  id: 1,
  title: "渡口的早晨",              // ← 水波紋中央顯示的中文主題
  audioSrc: "audio/track01.mp3",   // ← 對應的音檔路徑
  transcript: [                     // ← 逐字稿，每個字串是一個段落
    "第一段文字…",
    "第二段文字…"
  ]
}
```

直接修改 `title`、`transcript` 內容，並將對應的正式錄音檔放入 `audio/` 資料夾
（沿用同樣的檔名，或修改 `audioSrc` 指向新檔名）即可。

## 如何調整水波紋位置／大小

搜尋 `LAYOUT` 陣列，每一項對應同一順序的導覽主題：

```js
{ cx: 17, cy: 12.5, size: 25.5 }
```

- `cx` / `cy`：水波紋中心點在畫面上的位置（百分比，0~100）
- `size`：水波紋的直徑（相對畫面寬度的百分比）

目前的數值已依照您提供的示意圖手動標定，如需微調可直接修改數字並重新整理頁面預覽。

## 如何調整水波紋的視覺細節

搜尋 `buildOneRipple` 函式（在 `<script>` 內），開頭幾個常數對應了從官方水波紋
素材量測出來的比例，可依需要微調：

```js
const CORE_FRAC  = 0.158;   // 中央鏤空核心半徑 ÷ 整體半徑
const OVERLAP    = 1.9;     // 水波紋往外延伸多遠（越大，相鄰水波重疊越多）
const RING_COUNT = 13;      // 同心方框圈數（越少越簡潔）
const RX_RATIO   = 0.56;    // 圓角方形的轉角圓潤程度（squircle）
```

線寬由粗到細的漸變在 `widthFrac`（同一函式的迴圈中）調整，數值越大表示核心
線條越粗：

```js
const widthFrac = 0.026 - t * (0.026 - 0.0026);
```

左上到左下的 9 條彩色小色條則在同一函式下方的 `ACCENTS` 陣列中調整顏色、
半徑位置（`frac`）與型態（`edge` 直條 / `corner` 貼合轉角弧線）。

「向外流動」的動態水紋在 `FLOW_COUNT`（同時有幾圈在擴散）、
`flowDuration`（擴散一圈要幾秒）兩個變數中調整。

## 技術重點

- 純 HTML/CSS/JavaScript，無任何外部套件或 CDN 依賴，適合離線環境。
- 水波紋以 CSS 巢狀圓角方形（非圖片）即時運算繪製，可無失真縮放，
  在 iPad 視網膜螢幕（如 2160×1620）下依然銳利清晰。
- 畫面以 3:4 直式比例的「舞台」置中呈現，會依裝置螢幕自動縮放並維持比例，
  適合直接以 Safari 全螢幕或包裝成單一 App 使用。
- 中文字型使用系統內建字型（PingFang TC 等），iPad 上無需額外載入字型檔。
